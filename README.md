# Open Reading Library

> 一个面向普通读者的 **AI 辅助私人图书馆**：导入自己有权使用的电子书，在网页中连续阅读、划线、记笔记、检索，并由云端 AI 完成 OCR、摘要与知识回顾。

## 为什么做它

大多数阅读工具只管理文件或书目；大多数 AI 工具又脱离真实阅读上下文。Open Reading Library 希望把这条链路连起来：

**导入自己的书 → 直接阅读 → 选文留下判断 → 随时检索并回到原文。**

用户不需要本地 GPU：耗算力的 OCR、向量索引、摘要和复习任务可由托管服务异步完成；本地部署仍可选择关闭云端 AI。

## 当前阶段

这是公开项目的筹备仓库。现有个人原型验证了：

- EPUB、PDF、扫描书的阅读路径；
- 章节内分页、自动保存位置与真实进度；
- 阅读中选文摘录、个人感想、按书索引；
- 本地原书封面提取、分类与 SQLite 书目。

**注意：当前仓库不会包含任何用户书籍、封面、数据库、笔记、缓存或授权材料。**

## 公开版 MVP

1. 账户与私有书库隔离；
2. 仅允许用户上传自己拥有或获授权的文件；
3. EPUB / PDF 阅读、书签、摘录、笔记与全文检索；
4. 云端异步 OCR / AI 摘要（可关闭、可查看任务与成本）；
5. 私有对象存储、按用户授权的阅读与下载链接；
6. 托管版与自托管版共用核心代码。

## 发布前的明确边界

- 不提供盗版书源、频道抓取、公开书籍下载或共享书库。
- 不把用户上传的原书、摘录、笔记用于训练模型。
- AI 任务必须可见、可取消、可删除；默认私有。
