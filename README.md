# Open Reading Library

> 一个面向普通读者的 **私有云阅读图书馆**：导入自己有权使用的电子书，在网页中连续阅读、划线、记笔记和检索；AI 辅助能力将在第二阶段以可选方式加入。

## 为什么做它

大多数阅读工具只管理文件或书目；大多数 AI 工具又脱离真实阅读上下文。Open Reading Library 希望把这条链路连起来：

**导入自己的书 → 直接阅读 → 选文留下判断 → 随时检索并回到原文。**

用户不需要本地 GPU。第一阶段不接入 AI；耗算力的 OCR、摘要与知识回顾将在第二阶段作为可选托管能力加入。

## 当前阶段

这是公开项目的筹备仓库。现有个人原型验证了：

- EPUB、PDF、扫描书的阅读路径；
- 章节内分页、自动保存位置与真实进度；
- 阅读中选文摘录、个人感想、按书索引；
- 本地原书封面提取、分类与 SQLite 书目。

**注意：当前仓库不会包含任何用户书籍、封面、数据库、笔记、缓存或授权材料。**

## 第一阶段（当前公开方向）

先完成“私有云阅读与笔记”而非 AI：

- 账户与私有书库隔离；
- 仅允许用户上传自己拥有或获授权的文件；
- EPUB / PDF 阅读、书签、摘录、笔记与基础检索；
- 私有对象存储、按用户授权的阅读与下载链接；
- 书名、分类和封面元数据。

AI OCR、摘要、语义检索和复习卡作为第二阶段能力：届时再引入异步任务、模型 API、额度和收费。

## 发布前的明确边界

- 不提供盗版书源、频道抓取、公开书籍下载或共享书库。
- 不把用户上传的原书、摘录、笔记用于训练模型。
- AI 任务必须可见、可取消、可删除；默认私有。
