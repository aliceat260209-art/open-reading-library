# 隐私、版权与安全边界

## 允许的产品能力

- 用户上传、阅读和管理自己拥有或获授权的电子书；
- 对其私有文件生成封面、元数据、OCR、搜索索引、摘要和个人笔记；
- 用户主动分享自己创作的短笔记、书单或链接卡片。

## 不做的能力

- 不抓取 Telegram / 网盘 / 论坛 / 影子图书馆中的书；
- 不提供受版权保护电子书的公开下载、互传、公共全文检索或共享阅读；
- 不将用户文件、摘录或笔记用于训练基础模型；
- 不默认把用户书籍暴露给其他用户、管理员或搜索引擎。

## 上线前必须具备

1. 上传页的权利确认与举报入口；
2. 私有对象存储、短时签名访问与服务端权限检查；
3. 删除账户 / 删除书籍的异步彻底清理流程；
4. 文件隔离、病毒扫描、解压炸弹防护和 worker 资源上限；
5. AI 服务商数据保留设置、可关闭 AI、使用额度与费用提示；
6. 隐私政策、服务条款、版权投诉流程与支持联系方式。

## 公开仓库卫生

严禁提交：任何原书、封面扫描、SQLite 数据库、笔记、用户上传、缓存、访问令牌、`.env` 或包含私人阅读内容的截图。
